# tests/

Регрессионное покрытие для security-исправлений от 2026-08-17.

## Запуск

Внутри контейнера `wca`:

```bash
docker compose exec -T wca php /www/tests/run.php
```

Код возврата — `0` при успехе, `1` при любом падении, поэтому команду можно
ставить в CI как есть.

## Почему не PHPUnit

PHPUnit в проекте не установлен, а `composer.json` использует
`minimum-stability: dev` с несколькими `dev-master`-зависимостями — запуск
`composer require --dev` на рабочей инсталляции может подтянуть несовместимые
версии в `vendor/`. Раннер намеренно не имеет зависимостей: он использует только
`vendor/autoload.php`, который уже есть.

Когда PHPUnit понадобится, миграция прямолинейная — каждый кейс уже изолирован:

```bash
composer require --dev phpunit/phpunit ^9   # PHP 7.4 -> ветка 9.x
```

Затем каждый `tests/Unit/*Test.php` превращается в класс, наследующий
`PHPUnit\Framework\TestCase`, где `Assert::same()` → `$this->assertSame()`.

## Что покрыто

| Файл | Что защищает |
|------|--------------|
| `Unit/SqlIdentifierTest.php` | SQL-инъекция через `orderBy`: payload'ы не доходят до текста запроса, легитимная сортировка сохраняется, `LIMIT` остаётся числовым |
| `Unit/PasswordsTest.php` | Переход с несолёного sha1 на bcrypt; **старые sha1-аккаунты обязаны продолжать логиниться** и помечаться на пересчёт |
| `Unit/EncryptionTest.php` | Шифрование доступов к устройствам: случайный IV, encrypt-then-MAC, и **чтение значений, записанных прежней схемой** |
| `Unit/TrustedIpsTest.php` | Определение «внутреннего» вызова: некорректный ввод никогда не считается доверенным |

Кейсы про обратную совместимость (legacy sha1, legacy ciphertext) — самые
важные: их падение означает, что пользователи не смогут войти, а доступы к
устройствам перестанут расшифровываться.

## Добавление теста

Файл `tests/Unit/<Name>Test.php` возвращает массив `'имя кейса' => closure`:

```php
<?php
return [
    'описание того, что проверяем' => function () {
        Assert::same('ожидаемое', $actual, 'пояснение при падении');
    },
];
```

Доступны `Assert::true/false/same/notSame`. Константы `PROJECT_ROOT` и
`TEST_ROOT` определены в `bootstrap.php`.
